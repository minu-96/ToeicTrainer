## 단어 학습 방식

- **시작 화면**: 처음 열면 현재 점수대를 3개 중에서 골라요

| 점수대 | 하루 새 단어 | 시작 수준 | 빈칸 해석 | 기본 목표 |
|---|---|---|---|---|
| 500점 이하 | 10개 | 기초 | 바로 보임 | 700 |
| 500~750점 | 15개 | 중급 | 버튼 눌러야 | 850 |
| 750점 이상 | 20개 | 고급 | 버튼 눌러야 | 950 |

- **내장 단어**: 기초 120개 + 중급 80개 + 고급 80개
- **새 단어 순서**: 직접 추가 → 거르기에서 '몰라요' → 시작 수준 → 더 높은 수준 → 더 낮은 수준
- **아는 단어 빠르게 거르기**: 알아요/몰라요로 빠르게 넘기기. 알아요 → '익숙함'(일주일 뒤 빈칸 문제로 확인), 몰라요 → 다음 학습에 먼저 나옴. 방금 선택 되돌리기 가능

- **새 단어**: 5개씩 묶어서 ① 단어·뜻·예문 보며 외우기 → ② 뜻 고르기 → ③ 예문 빈칸 채우기. ②·③을 모두 맞혀야 끝남
  - 한 번도 안 틀림 → **익히는 중**(3일 뒤) / 1~2번 틀림 → **외우는 중**(내일) / 3번 틀림 → 그날은 넘기고 외우는 중 + 어려운 단어 기록
- **이미 아는 단어**: 처음 볼 때 "이미 알아요"를 누르면 '익숙함'으로 바로 이동 (하루 새 단어 수에서 빠짐)
- **복습 문제**: 외우는 중 → 뜻 고르기 / 익히는 중 → 예문 빈칸 / 익숙함 → 뜻 보고 단어 고르기 / 거의 외움·완벽 → 보기 없이 떠올리기
- **느린 정답**: 복습 문제를 맞혀도 10초 넘게 걸리면 단계 유지
- **어려운 단어**: 외우는 중으로 3번 이상 떨어진 단어. 다음 복습 때 단어 카드를 다시 보여준 뒤 문제를 내고, 약한 단어 연습에 우선 포함 (알았어요/헷갈렸어요/몰랐어요)
- **틀린 문제**: 3문제 뒤에 다시 출제. 한 학습에서 같은 단어를 3번 틀리면 붙잡지 않고 내일 다시. 모든 보기에 "모르겠어요" 버튼 (찍기 방지)
- **추가 학습**: 오늘 목표를 끝내면 "새 단어 10개 더", "약한 단어 연습"(외우는 중·익히는 중이거나 최근 7일 안에 틀린 단어. 맞혀도 일정 유지, 틀리면 '외우는 중'으로)

## 어휘 문제 (2단계)

- **문제 은행**: 직접 만든 Part 5 문제 60개 (`data/vocab-questions.json`), 유형 3가지 × 수준 3단계
  - 품사 자리: carefully / careful / care 중 빈칸에 맞는 품사
  - 어울리는 단어: comply with, waive a fee 같은 짝꿍 표현
  - 헷갈리는 단어: rise/raise, by/until, despite/although
- **오늘의 어휘 문제**(기본 10개): 틀렸던 문제(복습일 된 것) → 내 수준의 새 문제. 정답률이 가장 낮은 유형이 두 배로 나옴
- **해설**: 정답 단서, 설명, 해석, 보기별 뜻. 틀리면 이유 선택(뜻 몰라서 / 품사·문법 헷갈려서 / 시간에 쫓겨서 / 실수)
- **시간**: 문제마다 타이머, Part 5 목표 20초를 넘으면 표시
- **틀린 문제**: 다음 날 다시 출제, 맞히면 단어와 같은 간격(3일 → 7일…)으로 늦춰짐. 정답 단어는 예문과 함께 단어장에 자동 추가
- **3분 수준 진단**: 기초·중급·고급 5문제씩 → 수준별 정답률로 점수대 추천 (중급·고급 60% 이상 → 750점 이상, 중급 60% 이상 → 500~750점). 시작 화면·문제 탭·설정에서 실행

## 예상 점수 엔진 (v2.2)

실제 토익 구조를 따라 계산한다 (자세한 설계는 기획서 5장).

1. **기술별 능력 θ**: 어휘·문법·독해, LC 사진·응답·대화·담화. 문항 난이도 b(기초 −1.0 · 중급 0 · 고급 +1.2)와 정답 여부로 IRT(3모수, c = 찍기 확률) 격자 EAP 추정. 최근 기록일수록 무겁게(반감기 30일)
2. **단어 학습도 반영**: 단어 문제는 어휘 기술의 증거(무게 0.3, 하루 첫 답만, 유형별 난이도 보정)
3. **시간**: 목표 시간의 2배를 넘겨 맞히면 0.8개로 인정. RC는 파트별 풀이 시간으로 75분 안에 다 푸는지 확인하고, 못 푼 Part 7 문항은 찍기 25%만 인정
4. **파트별 기대 정답 수**: 실제 문항 수(Part 1~7: 6·25·39·30·30·16·54) × 파트 난이도 분포 위 정답 확률
5. **환산**: LC·RC 맞힌 개수 → 5~495점 (공식 환산표가 없어 근사 구간 선형), 총점 = LC + RC
6. **범위**: θ 분포에서 300번 뽑아 80% 구간 + 영역별 모델 오차 ±25
7. **성적 기록**: 교재 모의고사 파트별 맞힌 개수(강한 증거) · 공식 성적(LC·RC 차이만큼 보정)
8. **화면**: 홈에 총점·LC·RC·범위·미측정 표시·지난주 대비 변화 이유, 분석 탭에 파트별 예상 정답과 점수를 가장 많이 올릴 파트

## 독해와 실전형 듣기 (v5)

- 유형 8가지: 주제·목적, 세부 정보, NOT·TRUE, 추론, 동의어, 문장 위치, 의도 파악, 연계(두 지문). 문제당 목표 1분.

- 틀린 문제가 있는 지문은 다음 날 다시 나와요. 점수는 독해(reading) 능력에 반영 (동의어는 어휘와 반반).
- **Part 3·4 실전형**: 7줄 대화, 3인 대화, 시각 자료(회의실·요금·영업시간·매출 표) 문제, 화자 의도 문제 7세트 추가. Part 3 16세트 · Part 4 15세트.
- 세트 문제의 정답 위치를 A~D에 고르게 나눴어요 (예전에는 B에 몰려 있었음).
- **진단에 듣기**: 수준마다 Part 2 한 문제씩, 진단 전용 3문제. 소리가 안 나면 건너뛸 수 있어요. 결과에 듣기 맞힌 수가 나와요.

## 듣기 보강과 하루 학습 시간 (v4.1)

- **듣기 문제 3배**: Part 2 90문제(수준별 30), Part 3 대화 12세트(3인 대화 2), Part 4 담화 12세트.
- **하루 학습 시간**: 시작 화면·설정에서 15 · 25 · 40 · 60분 중 고르면, 오늘 복습 시간을 먼저 빼고 남은 시간을 새 단어 · 듣기 · 어휘 · 문법에 나눠요(js/plan.js). 저득점은 듣기·새 단어, 고득점은 문법·어휘 비중이 커요. 복습이 많아도 40%는 다른 학습에 남겨요. '직접 정하기'를 고르면 예전처럼 숫자대로.
- **성장 기록**: '어휘 정답률'을 '문제 정답률'로 바꾸고, 어휘 · 문법 · 장문 빈칸 · 듣기 영역별 정답률 카드를 추가. 학습량·정답률·단어 그래프와 달력·기록은 '그래프 더 보기'로 접었어요.

- **음성 실패 안내**: 끝까지 재생했는데 소리가 한 번도 시작되지 않으면 '소리가 안 들리나요?'(무음 모드·음량 확인 → 대본 보고 풀기)를 띄워요.

## 듣기 (v4)

- **오늘 할 일에 듣기 추가**: 단어 → 듣기(Part 2 10문제) → 어휘 → 문법. 저득점 구간은 LC부터 올리는 게 일반적인 전략이라 두 번째에 뒀어요.
- **Part 2 응답 (30문제)**: 질문과 응답 A·B·C를 음성으로만 듣고 고르기. 답한 뒤 대본과 함께 오답 보기의 함정(비슷한 발음 · 같은 단어 반복 · 관련 단어 연상 · 질문과 안 맞는 답)을 표시해요. 간접 응답·부정 의문문·제안 의문문 포함.
- **Part 3 대화 (6세트, 3인 대화 포함) · Part 4 담화 (4세트)**: 문제와 보기를 먼저 읽고(선독) → 듣기 시작 → 들으면서 고르기 → 채점 후 대본·해석. 해설에 바꿔 말하기(paraphrase)를 짚어 줘요.
- **받아쓰기**: Part 2 질문 문장을 듣고 쓰면 낱말별로 맞은 것·놓친 것을 보여 줘요(점수에는 미반영).
- **음성**: 화자마다 다른 목소리(여·남·남2·내레이터). 기기에 있으면 미국·영국·호주 억양을 섞고, 없으면 높낮이로 구분해요. 설정에서 억양 섞기와 듣기 속도(느리게·보통·빠르게)를 바꿀 수 있어요.
- **점수 반영**: Part 2 → lc_qr, Part 3 → lc_conv, Part 4 → lc_talk. 브라우저 음성이 실제보다 쉬워서 무게는 0.6, Part 2 찍기 확률은 1/3로 계산해요. 음성이 안 나와 '대본 보기'로 푼 문제는 점수에서 빠져요.
- Part 1(사진 묘사)은 사진이 필요해서 교재로 연습하도록 안내해요. 듣기 오답은 아직 오답 탭에 모이지 않아요(틀린 문제는 다음 날 다시 나와요).

## UX 개편 (v3.4)

처음 쓰는 사람 기준으로 화면마다 높이와 버튼 위치를 재서 우선순위대로 고쳤어요.
1. **풀이 화면 (매 문제마다 반복되는 비용)**: 답하면 화면 아래에 버튼이 고정돼요. 맞히면 '다음 문제', 틀리면 이유 4개(고르면 바로 다음). 해설은 판정·단서·설명만 바로 보이고 해석·보기별 뜻은 접어 둬요(틀렸을 때는 펼침). 장문 빈칸 지문은 상자 안에서 스크롤되고 지금 빈칸이 보이게 맞춰요.
2. **문제 탭 (3.2화면 → 1화면)**: 위에서 어휘 · 문법 · 장문 빈칸을 고르고 그 영역만 보여 줘요. 유형은 2열 타일, 문법 개념 카드는 가로 칩, 스피드 모드·진단은 아래 한 줄.
3. **단어 탭 (23화면 → 4화면)**: 목록은 40개씩 '더 보기'. 단어 진행 상황은 홈에서 단어 탭 위로 옮기고 접어 둬요.
4. **홈·설정**: 홈은 점수·오늘 할 일 중심(1.2화면). 설정의 숫자 칸은 2열로, '오늘의 문제 수(어휘·문법 각각)'처럼 이름을 고쳤어요.

## 문항 품질 보완 (v3.3)

토익 출제자 관점 검토 결과를 반영했어요.
- **문장 길이를 수준별로 점점 길게**: Part 5 문장 평균 기초 약 10단어 → 중급 약 13단어 → 고급 약 17단어(실전 수준). 수식어가 붙어도 단서(시간 표현, 진짜 주어 등)를 찾는 연습이 되도록 고쳤고, 해석도 함께 바꿨어요.
- **정답이 둘이던 문항 수정**: 현재형으로도 맞던 미래 시제, is로도 맞던 조건문, below budget, very affordable, will open/will be opened 등.
- **실제로 없는 형태의 보기 제거**: more light, most large, to benefited 같은 보기를 실제 단어(lightly, largely, benefits …)로 바꿨어요.
- **정답이 가장 긴 보기로 쏠리지 않게**: 어울리는 단어 20문항의 보기 길이를 맞추고, 자동 검사(35% 이하)를 넣었어요.
- **Part 6 문장 넣기**: 오답 보기를 같은 주제 안에서 앞뒤 내용과 모순되는 문장으로 바꿨어요. 앞 문장을 봐야 시제가 정해지는 빈칸, 연결어 빈칸을 추가해 모든 지문에 문맥으로 푸는 빈칸이 2개 이상 있어요.
- **바꿔 쓰는 표현**: 지문 단어 형태(-ed, -s, -ing)에 맞춰 보기도 같은 형태로 바꿔요(canceled → called off, colleagues → coworkers).
- **분류 정리**: 어휘의 '헷갈리는 단어'에 있던 접속사·전치사 문항 9개를 문법 '전치사 vs 접속사'로 옮겼어요.

## 장문 빈칸 (v3.2)

- **지문 12개 · 빈칸 48개**: 이메일·공지·광고·메모·기사·편지, 수준별 4지문. 빈칸 유형은 어휘 · 문법 · 연결어 · 문장 넣기.
- **화면**: 지문 전체를 위에 두고 지금 빈칸만 강조해요. 앞에서 푼 빈칸은 정답으로 채워져 흐름을 보며 다음 빈칸을 풀 수 있어요. 문항당 목표 30초.
- **지문 해석은 다 푼 뒤에**: 해석에 정답이 들어 있어서 결과 화면에서만 보여 줘요.
- **다시 내기**: 틀린 빈칸이 있는 지문은 다음 날 먼저 나오고, 오답노트에서 다시 풀 때도 지문과 함께 나와요.
- **점수 반영**: 어휘 → 어휘, 문법 → 문법, 연결어 → 문법·독해 반반, 문장 넣기 → 독해. 기록은 part 6, 목표 30초로 남아 RC 시간 계산에도 쓰여요.
- 문제 탭에 '장문 빈칸' 카드(유형별 정답률, 지문 1개 풀기). 오늘 할 일에는 넣지 않았어요.

## 사용자 테스트 보완 (v3.1)

- **오늘 할 일 카드**: 홈 맨 위에 단어 · 어휘 문제 · 문법 문제 세 줄과 남은 시간. 줄을 누르면 그 학습으로, 큰 버튼은 아직 안 한 다음 할 일로 가요.
- **다음 할 일 이어가기**: 단어 학습·오늘의 문제 결과 화면에 '다음: …' 버튼과 오늘 남은 것을 보여 줘요. 단어만 끝났을 때는 '오늘 단어 끝!'으로 표시해요.
- **결과 숫자 맞춤**: 단어 결과의 비율을 '안 틀린 단어'(단어 단위)로 바꿔 아래 단계 이동과 같은 기준이 되게 했어요.
- **틀린 이유 바로 고르기**: 틀리면 이유 버튼 4개가 다음 버튼 자리에 나오고, 고르면 바로 다음 문제로 넘어가요. '이유 없이 넘기기'도 있어요.
- **진단에 문법 포함**: 3분 진단 15문제를 어휘 9 + 문법 6(진단 전용)으로 바꾸고 결과에 영역별 정답 수를 보여 줘요.
- 단어 목록은 학습 중인 단어(복습일 순) → 새 단어(시작 수준 순)로 정렬, 측정 안내 문구 조사 수정.

## 문법 (v3)

- **문법 기초 3장**: 문장의 뼈대 · 품사와 자리 · 동사의 세 가지 결정(수 → 태 → 시제). 문법을 처음 시작하면 홈과 문제 탭에서 안내해요.
- **유형 10개 · 120문제**: 시제, 수일치, 능동·수동, 동명사·to부정사, 분사, 관계사, 전치사 vs 접속사, 대명사, 비교, 가정법·도치. 유형마다 기초·중급·고급 4문제씩.
- **개념 카드**: 유형마다 핵심 규칙, 예문, 빠른 단서. 처음 푸는 유형은 카드를 먼저 보여 주고, 해설에서 '개념 다시 보기'로 언제든 열 수 있어요.
- **오늘의 문법 문제**: 하루 10문제(어휘와 같은 설정값), 틀린 문제 다시 내기와 약한 유형 우선은 어휘와 같아요. 스피드 모드에는 어휘·문법 Part 5 문제가 섞여 나와요.
- **점수 반영**: 문법 풀이는 점수 엔진의 문법(grammar) 영역에만 반영되고, 오답 정답이 단어장에 추가되지 않아요.

## 어휘 보강 (v2.4)

- **문제 은행**: 연습 150문제(유형 3개 × 수준 3개, 칸마다 15개 이상) + 진단 전용 15문제. 진단 문제는 연습에 나오지 않아서 다시 봐도 같은 기준으로 비교돼요.
- **바꿔 쓰는 표현**: 내장 단어의 바꿔 쓰는 표현으로 만든 Part 7 대비 문제(약 220개). 예문의 밑줄 친 단어와 뜻이 가장 가까운 것을 고르는 형식이에요. 뜻이 겹치는 단어끼리는 오답 보기로 쓰지 않아요.
- **스피드 모드**: 내 수준 Part 5 문제 10개를 3분 안에. 해설 없이 바로 넘어가고, 결과에서 걸린 시간·문제당 평균·최고 기록을 보여 줘요.
- **수준 자동 조정**: 지금 수준 문제 최근 20개 정답률이 80% 이상이면 한 단계 위로 올리고(되돌리기 가능), 40% 미만이면 내리기를 제안해요. 진단이나 설정으로 수준을 바꾸면 그 뒤 기록만 다시 세요.

## 빠른 보완 (v2.3)

- **오답 탭**: 해결 안 된 어휘 문제·자주 틀린 단어, 최근 30일 틀린 이유 통계. '오답만 다시 풀기'에서 두 번 연속 맞히면 '해결함'으로 옮겨져요. 단어는 '익숙함'까지 올라가면 빠져요.
- **복습 상한**: 하루 복습은 기본 60개까지(설정에서 변경). 밀린 복습이 상한의 절반을 넘으면 새 단어를 절반으로, 상한을 넘으면 0개로 줄여요. 오늘 몫을 끝내면 '밀린 복습 더 하기'가 나와요.
- **문제 신고**: 해설 화면과 단어 상세에서 '이 문제 이상해요'. 신고한 문제·단어는 점수 계산과 새 출제에서 빠지고, 설정에서 목록 확인·취소·복사할 수 있어요.
- **백업 안내**: 마지막 백업 후 7일이 지나면 홈에 안내가 떠요.
- **미측정 안내**: LC나 Part 7을 아직 측정하지 않았으면 홈에 카드로 알려 줘요.
- **자동 테스트**: `tests/README.md` 참고 (`npm test`, `npm run e2e`).
