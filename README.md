# 토익 트레이너

약점만 골라 반복하는 개인용 토익 학습 도구 (PWA). 목표: 400 → 800

## 기능 로드맵

| 단계 | 기능 | 상태 |
|---|---|---|
| 1 | 단어: 5개 묶음 암기 → 뜻 고르기 → 예문 빈칸, 단계별 복습, 추가 학습, 백업 | ✅ v1.4 |
| 2 | 어휘: Part 5 품사 자리·어울리는 단어·헷갈리는 단어 60문제, 3분 수준 진단 | ✅ v2 |
| 3 | 문법: Part 5 유형별 문제 | |
| 4 | 독해: Part 7 + 시간 제한 | |
| 5 | 듣기: TTS로 Part 2, 받아쓰기 | |
| 6 | 오답노트: 앱 오답 + 교재 오답 기록 | |
| 7 | 분석: 예상 점수·일/주/월 성장 기록 ✅ v2.1 / 약점 분석(실수 유형 TOP 3) 예정 | 일부 |

## 단어 학습 방식

- **시작 화면**: 처음 열면 현재 점수대를 3개 중에서 골라요

| 점수대 | 하루 새 단어 | 시작 수준 | 빈칸 해석 | 기본 목표 |
|---|---|---|---|---|
| 500점 이하 | 10개 | 기초 | 바로 보임 | 700 |
| 500~750점 | 15개 | 중급 | 버튼 눌러야 | 850 |
| 750점 이상 | 20개 | 고급 | 버튼 눌러야 | 950 |

- **내장 단어**: 기초 120개 + 중급 80개 + 고급 80개
- **새 단어 순서**: 직접 추가 → 거르기에서 '몰라요' → 시작 수준 → 더 높은 수준 → 더 낮은 수준
- **아는 단어 빠르게 거르기**: 알아요/몰라요로 빠르게 넘기기. 알아요 → '익숙함'(일주일 뒤 빈칸 문제로 확인), 몰라요 → 다음 학습에 먼저 나옴. 방금 선택 되돌리기 가능

- **새 단어**: 5개씩 묶어서 ① 단어·뜻·예문 보며 외우기 → ② 뜻 고르기 → ③ 예문 빈칸 채우기. ②·③을 모두 맞혀야 끝남
  - 한 번도 안 틀림 → **익히는 중**(3일 뒤) / 1~2번 틀림 → **외우는 중**(내일) / 3번 틀림 → 그날은 넘기고 외우는 중 + 어려운 단어 기록
- **이미 아는 단어**: 처음 볼 때 "이미 알아요"를 누르면 '익숙함'으로 바로 이동 (하루 새 단어 수에서 빠짐)
- **복습 문제**: 외우는 중 → 뜻 고르기 / 익히는 중 → 예문 빈칸 / 익숙함 → 뜻 보고 단어 고르기 / 거의 외움·완벽 → 보기 없이 떠올리기
- **느린 정답**: 복습 문제를 맞혀도 10초 넘게 걸리면 단계 유지
- **어려운 단어**: 외우는 중으로 3번 이상 떨어진 단어. 다음 복습 때 단어 카드를 다시 보여준 뒤 문제를 내고, 약한 단어 연습에 우선 포함 (알았어요/헷갈렸어요/몰랐어요)
- **틀린 문제**: 3문제 뒤에 다시 출제. 한 학습에서 같은 단어를 3번 틀리면 붙잡지 않고 내일 다시. 모든 보기에 "모르겠어요" 버튼 (찍기 방지)
- **추가 학습**: 오늘 목표를 끝내면 "새 단어 10개 더", "약한 단어 연습"(외우는 중·익히는 중이거나 최근 7일 안에 틀린 단어. 맞혀도 일정 유지, 틀리면 '외우는 중'으로)

## 어휘 문제 (2단계)

- **문제 은행**: 직접 만든 Part 5 문제 60개 (`data/vocab-questions.json`), 유형 3가지 × 수준 3단계
  - 품사 자리: carefully / careful / care 중 빈칸에 맞는 품사
  - 어울리는 단어: comply with, waive a fee 같은 짝꿍 표현
  - 헷갈리는 단어: rise/raise, by/until, despite/although
- **오늘의 어휘 문제**(기본 10개): 틀렸던 문제(복습일 된 것) → 내 수준의 새 문제. 정답률이 가장 낮은 유형이 두 배로 나옴
- **해설**: 정답 단서, 설명, 해석, 보기별 뜻. 틀리면 이유 선택(뜻 몰라서 / 품사·문법 헷갈려서 / 시간에 쫓겨서 / 실수)
- **시간**: 문제마다 타이머, Part 5 목표 20초를 넘으면 표시
- **틀린 문제**: 다음 날 다시 출제, 맞히면 단어와 같은 간격(3일 → 7일…)으로 늦춰짐. 정답 단어는 예문과 함께 단어장에 자동 추가
- **3분 수준 진단**: 기초·중급·고급 5문제씩 → 수준별 정답률로 점수대 추천 (중급·고급 60% 이상 → 750점 이상, 중급 60% 이상 → 500~750점). 시작 화면·문제 탭·설정에서 실행

## 예상 점수 · 성장 기록 (v2.1)

- **홈 예상 점수**: 최근 어휘 문제 최대 60개의 수준별 정답률로 계산 (10문제 이상부터 표시)
  - 수준별 정답률에 기본값(기초 75%·중급 50%·고급 30%)을 2문제만큼 섞어 흔들림을 줄임
  - 가중 평균(기초 0.4·중급 0.35·고급 0.25) θ → `60 + 925 × θ` (10~990, 5점 단위)
  - 범위는 푼 문제 수가 많을수록 좁아짐, 지난주 대비 변화와 목표까지 남은 점수 표시
  - 대략적인 추정값. 문법·독해·듣기가 생기면 함께 반영
- **분석 탭 (성장 기록)**: 일(14일)·주(8주)·월(6개월) 전환
  - 이번 기간 vs 지난 기간: 예상 점수, 학습일, 답한 수, 새로 배운 단어, 정답률
  - 그래프: 예상 점수 추이(목표 기준선), 학습량(단어·어휘 문제), 정답률, 익숙함 이상 단어 수
  - 최근 12주 학습 달력, 연속·최장 연속 학습일 등 기록
  - 그래프를 누르면 그 기간 값이 툴팁으로 표시, 색은 색각 이상 검사를 통과한 2색만 사용

## 간격 반복 규칙

| 단계 | 다음 복습 |
|---|---|
| 외우는 중 | 1일 뒤 |
| 익히는 중 | 3일 뒤 |
| 익숙함 | 7일 뒤 |
| 거의 외움 | 14일 뒤 |
| 완벽 | 30일 뒤 |

- 맞힘(10초 이내): 한 단계 위 / 맞힘(10초 넘음): 그대로 / 헷갈림: 한 단계 아래 / 틀림: '외우는 중'으로, 그 학습 안에서 다시 맞혀야 함
- 하루 새 단어 수(기본 20개)는 내장 단어에만 적용. 직접 추가한 단어는 바로 나옴

## 파일 구조

```
index.html          화면 뼈대
css/style.css       스타일 (다크 모드, 아이폰 safe-area 대응)
js/app.js           화면과 동작
js/srs.js           간격 반복 계산
js/storage.js       저장소 접근 (여기만 바꾸면 Capacitor/IndexedDB로 교체 가능)
js/tts.js           발음 듣기 (브라우저 TTS)
js/quiz.js          문제 만들기 (뜻 고르기, 단어 고르기, 예문 빈칸)
js/session.js       학습 순서와 결과 처리
js/vocab.js         어휘 문제 출제·기록·수준 진단
js/stats.js         예상 점수, 기간별 성장 지표
js/charts.js        SVG 차트 (선·쌓인 막대, 툴팁)
data/words-basic.json  내장 기초 단어 (120개)
data/words-mid.json    내장 중급 단어 (80개)
data/words-adv.json    내장 고급 단어 (80개)
data/vocab-questions.json  어휘 문제 (60개)
manifest.json, sw.js   PWA 설치·오프라인
icons/              앱 아이콘 (tools/make_icons.py로 생성)
```

## 로컬에서 실행

```bash
python3 -m http.server 8000
# http://localhost:8000
```

`index.html`을 파일로 바로 열면 모듈과 서비스 워커가 동작하지 않으니 꼭 서버로 여세요.

## 배포 (GitHub Pages)

1. 레포 Settings → Pages → Branch: `main` / `(root)` → Save
2. 주소: https://minu-96.github.io/ToeicTrainer/
3. 아이폰 Safari에서 열고 공유 → **홈 화면에 추가**

## 업데이트할 때

앱 파일을 고친 뒤에는 `sw.js`의 `CACHE` 버전을 올리세요 (예: `toeic-trainer-v2` → `v3`).
휴대폰에서는 앱을 한 번 열었다 닫고 다시 열면 새 버전이 적용돼요.

## 데이터

- 학습 기록은 기기 브라우저(localStorage)에만 저장돼요. 주소가 바뀌면 기록이 안 보이니 설정 → **백업 파일 저장**을 가끔 해 두세요.
- 풀이 기록(`attempts`)은 1단계부터 쌓이며, 7단계 약점 분석에 사용돼요.
